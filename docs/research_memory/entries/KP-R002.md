## 질문

η3=0.1 조건에서 n과 context에 따른 κ의 분산이 signal pair와 control pair에 어떻게 나타나는가? 이 질문은 현재 README와 Fig.3/4 recipe에서 재구성한 것으로, 동시대 실험 일지의 직접 인용은 아니다.

## 이유

현재 README와 그림 처리 코드가 η3 sweep·signal/control 비교를 설명한다. 원 metadata는 조건·출력을 남기지만 이 시도의 선택 이유나 사전 가설은 별도로 보존하지 않는다.

## 시도·변경

보존된 wrapper run=2의 η3=0.1 설정에서 n=2…7을 실행하고 동일 trial seed base로 shot noise와 piecewise-constant drift를 포함한다.

## 조건

- η3=0.1, wrapper run=2; n=2…7의 execution 6개. 보존 timestamp는 2026-01-11 UTC, 한국시간 2026-01-12이다.
- n별 20 trial, seed_base=20251224; 측정 설정당 2048 shots, shot.enabled=true.
- drift.enabled=true, sigma=0.02, piecewise_constant, chunk_shots=32, hold_chunks=4, schedule=interleave, schedule_seed=1234.
- pair (0,1)는 모든 n, control pair (2,3)는 n≥4; 각 pair에서 2^(n−2) context를 exhaustive하게 처리한다.
- exhaustive 설정 때문에 요청된 context_samples=64와 context_seed=1234는 무시됐다는 원 metadata를 보존한다.

## 관측·확인한 내용

- 6개 metadata execution ID와 6개 stats input_run_dir가 일치한다. rows에는 run_id가 없으므로 고유한 η3/n 묶음과 trial_summary.run_id를 통해 연결했다.
- 보존된 2,460 context 행과200 pair-trial 요약이 전체 예상 pair/context/trial 조합과 일치한다. n별 20 trial을 합친 120개 trial 단위이며200개는 pair별 요약 수다.
- 이번 정리의 read-only 산술 검산에서 저장된 요약이 raw row 재집계와 일치했다. 작은 V 값의 과학적 표기 반올림을 포함한 오차 허용은 5e-8이다.
- 보존된 n=7 trial summary의 V_circ 평균: pair(0, 1)=0.0022514619, pair(2, 3)=0.0003955617. 이번 정리에서 기존 summary를 평균한 값이며 새 simulation 또는 과거 figure의 bootstrap point가 아니다.

## 해석

같은 보존 조건의 η3 비교와 signal/control 재분석에 재사용할 수 있는 완료된 출력 묶음이다. 개별 trial 및 pair의 의존성을 유지하고, 다른 조건·장치로의 일반화나 원래 전체 탐색의 완전성을 이 묶음만으로 주장하지 않는다.

## 한계와 미확인 사항

- 원 sim metadata에는 model YAML hash, 실행 코드 commit/dirty state, 환경 version, exit_code/errors가 없다. 현재 model/runner는 재현 후보이며 실제 실행 바이트로 확정할 수 없다.
- 원 raw rows에는 run_id가 없고 합쳐진 CSV가 반올림돼 있다. source hash와 η3/n/pair/trial selector를 함께 유지해야 한다.
- 같은 seed_base=20251224와 trial_id=0…19가 n·η3 조건들에서 반복된다. 120개 n별 trial 인스턴스나200개 pair summary를 모두 독립 표본으로 간주하지 않는다. 현재 runner recipe는 seed_base+trial_id를 사용하지만 실행 당시 코드 identity는 미확인이다.
- wrapper run=2 이전의 run=1, 실패·중단 이력이나 누락된 시도가 있었다는 것을 이 자료에서 확정할 수 없다.
- 두 저장소에 동일 바이트가 존재하므로 같은 과거 실험을 두 번의 독립 반복으로 계산하지 않는다.
